## Request and permanent identity boundary

Commit `b1eff1c` adds strict bounded research-request validation: a question, explicit goal/project references, one exact revision per admitted source, named acceptance criteria and structural limits. Defaults are two attempts, four model turns, 24 tool calls, one concurrent worker, 600 seconds, 32 KiB context and 8 KiB result. These are intended root limits across attempts, not fresh allowances per retry; runtime accounting is still to be implemented. Validation rejects caller-supplied identity, approvals, tools, destinations and provider choices. It does not establish source access or execution authority, and no mission RPC is exposed yet.

Commit `352a65d` adds permanent host-local child markers, keyed by attempt with unique execution group and session. Exact replay preserves the marker; changing its mission, scope, generation, group or session is refused. A marker is a restriction, never an execution grant. Child groups have no messaging-group binding, cannot acquire coordinator authority, and remain denied by the generic launcher, outbound gate and mutable-state gate while CoS is absent. Malformed markers and partial identity substitutions do not fall back to ordinary agents. Ordinary sessions remain available. Native Mattermost A2A restrictions are unchanged.

Both increments followed red → green. Initial runs failed because their implementations were absent; 34 request tests and 13 specialist-boundary tests then passed. All **1,792 host tests across 181 files** passed, including existing native routing, Mattermost and coordinator regressions. Host typecheck passed. Scoped formatting and lint passed after repairing one caught-error lint violation; the existing coordinator file retains three lint warnings. The focused 24-test child/coordinator suite passed again after that repair. No worker code changed; the prior 176 worker-test result belongs to S04 and is not new S05 worker acceptance.

## Immutable work orders and storage

Commit `c6a0b6d` defines the versioned admitted-note comparison template and seals a deeply copied, frozen work order. It pins private origin, related-record versions, exact source revisions and contiguous normalized locators, context digest, operator-reviewed template digest, provider/model policy, deadline, acceptance criteria and structural limits. The template permits only mission-context reads and result submission. Context size is measured in UTF-8 bytes; oversized or incomplete context is refused rather than silently truncated. This pure snapshot function does not establish current source access or operator approval by itself; the trusted admission path remains to be connected.

Eight work-order tests pass. They first exposed the absent implementation and then a valid empty-line chunk incorrectly rejected by the validator; the latter was corrected while retaining exact locators. The affected contract/knowledge suite passed 169 tests. Typecheck and scoped lint/format passed.

Commit `8d1354b` adds migration 7 on the separate protected external test database only. It introduces template versions, context manifests, immutable work orders, mission/attempt state, root usage reservations, result submissions and recorded reviews. Runtime credentials can read but cannot install or edit reviewed templates; work orders, manifests, reservations, submitted-result records and reviews allow insert/read but not update/delete. Attempt execution identities and input IDs are unique. Reservations reference the exact mission, attempt and generation and cannot be duplicated under a different call kind. These are storage constraints, not evidence that complete runtime budget or approval enforcement is connected.

The two new external-database scenarios first failed on missing tables and now pass. A subsequent test repair compares table existence independently of PostgreSQL's search-path-dependent display of relation names, and checks SELECT/INSERT privileges separately. All 22 mission-schema, existing-priority and work scenarios pass against real external PostgreSQL. All **1,801 host tests across 182 files**, typecheck and scoped lint/format pass. An old S04 release fixture had incorrectly included all future migrations; it now pins its six migrations and rejects extra migration claims. S05 release construction remains unregistered until its full flow is implemented.
