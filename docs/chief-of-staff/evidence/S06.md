## Graph admission increment

The first increment defines four immutable specialist templates and a strict
four-to-six-step graph. Independent technical and operational analysis precede
one writer and one reviewer. Every step names its dependencies, submitted-artifact
inputs, exact source revisions, criteria, result schema, limits and bounded rework.
Validation rejects cycles, duplicate or unknown dependencies, unsupported templates,
source expansion, private-context fields and incomplete joins. Only host-validated
reviewed template digests and an exact owner approval may authorise execution;
these pure contracts do not provide either.

The root covers all reserved step attempts, retries, rework, model turns and tool
calls. Rework adds no turn/tool allowance. Structural concurrency is capped at two;
native capacity reservation and root-budget persistence are still required. The
existing S05 single-worker request and defaults are unchanged. Public retrieval
remains disabled; no search service or network permission is added.
